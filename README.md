# 🧠 Tower of Hanoi – Futuristic AI Puzzle Game

A visually stunning and interactive implementation of the classic **Tower of Hanoi** puzzle built using pure **HTML, CSS, and JavaScript**.

This project combines:
- ⚡ Futuristic cyberpunk-inspired UI
- 🤖 AI-powered automatic solver
- 🎮 Drag-and-drop gameplay
- ✨ Particle systems & animated backgrounds
- 🚀 Real-time speed controls
- 📱 Responsive design

---

## 🎥 Preview

Live Demo: https://tower-of-hanoi-ai-beta.vercel.app/

---

# ✨ Features

## 🎮 Gameplay
- Classic Tower of Hanoi puzzle
- Manual play mode
- Drag & Drop disk interaction
- Click-based movement support
- Real-time move counter
- Timer system
- Wrong move detection

---

## 🤖 AI Solver
- Fully automatic optimal puzzle solving
- Dynamic move generation
- Adaptive solving from current game state
- Adjustable solving speed (0.5× → 5×)

---

## 🎨 Visual Effects
- Futuristic neon-inspired interface
- Animated VIBGYOR particle background
- Motion trails
- Ripple impact effects
- Floating grid animation
- Dynamic glowing disks
- Celebration particle effects

---

## ⚡ Performance
- Pure Vanilla JavaScript
- No external game engine
- Optimized animations using requestAnimationFrame()
- Lightweight and fast rendering

# 🎯 Controls

| Action | Control |
|--------|---------|
| Move Disk | Drag & Drop / Click |
| Increase Disks | + Button |
| Decrease Disks | - Button |
| Start AI Solver | Solve Button |
| Reset Game | Reset Button |
| Speed Control | Slider / Arrow Buttons |
| Pause Solver | Pause Button |

---

# 🧩 Puzzle Rules

1. Only one disk can be moved at a time
2. A larger disk cannot be placed on a smaller disk
3. Move all disks from Peg A to Peg C
